# Crimson Player 1.1.0

- Apply EQ to compatible audio from other apps through Android's output mix, with a foreground service that keeps it running after closing the screen.
- Add 20 genre profiles: Hip-hop, Rap, Ballad, Pop, Rock, Jazz, Classical, Acoustic, EDM, R&B, Metal, Country, Blues, Reggae, Latin, K-pop, V-pop, Lo-fi, Soul, and Instrumental.
- Save changes to the selected profile, revert to its last save, or save a new profile. Keep unsaved drafts separate for each profile.
- Reduce startup work: reuse the running EQ, create local playback only when needed, scan the library in the background, and update individual EQ bands without rewriting the whole stage.
- Keep the timeline close to the artwork while providing a 48dp touch target, without a round handle. Hold the selected position until the source acknowledges the seek.
- Fix the status-bar logo and remove the black launcher-icon background.
- Refresh the README screenshots from FiiO M11S and remove the extra Android output note from the EQ screen.

Validation: debug build, Android lint, and hardware integration tests on FiiO M11S (Android 10), including Save/Revert, genre defaults, service restoration, and reopening the activity while EQ stays enabled.

System-wide EQ depends on firmware. Direct, offloaded, bit-perfect, DSD, and exclusive USB output can bypass Android's audio mix. Force-stopping the app stops EQ; reopen it to restore the saved enabled state. Local playback still runs in the activity. Android 6.0 or later is required.

The APK uses the same Android debug signing key as 1.0.0 and is intended for testing. Install over the existing version to retain app data.
